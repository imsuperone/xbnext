XBNEXT 0.1.1

引用占位清洗

清理引用链里 core 塞入的 [Empty Text] / [Image unavailable] 占位噪声，并把失效的引用图片明确标注给模型，杜绝"凭空出现的空白图片"。修正类功能，开启会改写本轮请求。

QQ 表情翻译

把消息链里的 face / mface 翻译成文字描述追加进本轮请求。aiocqhttp 默认会把表情丢在 message_str 之外，不开启等于表情全部丢失。修正类功能。

回复指向索引

记录 bot 每条回复"回给谁"，下一轮给出三方区分说明，避免把 A 问过的话套到 B 头上。新增行为，默认关闭。

用户档案注入

每轮按当前发言人注入其自助档案，让 bot 按档案理解用户而不是乱猜。档案按不可信输入清洗后注入，且不写入会话历史。新增行为，默认关闭。

撤回取消请求

撤回刚发的那条消息时，取消这条消息正在飞的 LLM 请求 —— 省一次白烧的 token，也避免 bot 对着已撤回的消息回一整段；bot 已发出的回复也会连带撤回（aiocqhttp 下生效）。默认开启。

历史图片瘦身

把对话历史里较旧消息携带的图片换成文字占位，大幅减少输入 token（一张截图动辄几千 token）。最近 6 条消息的原图保留，当轮刚发的图不受影响。改写类功能，默认关闭。

Token 用量展示

回复末尾追加一行本轮 token 用量（输入 / 输出 / 缓存），仅对「行为微调」里指定名单内的会话显示。默认关闭。

引用占位处理方式

决定识别到引用占位符后怎么处理。仅在「引用占位清洗」开启时生效。

标注失效会把 [Image unavailable] 改写成中文说明（推荐）；直接删除会连同图片存在性一起抹掉；仅记录不改写请求。

移除失效图片路径

只删「能证实已失效」的本地路径，http/https/data 与无法离线判断的一律保留；移除后会把正文里的裸 [Image] 一并标注为已失效，杜绝模型臆想出一张空白图。仅在「引用占位清洗」开启时生效。

表情翻译格式

{name} 会被替换成表情中文名，取不到名字时替换成表情 ID。仅在「QQ 表情翻译」开启时生效。

例如 [表情:得意]、[表情:ID12345]。

表情表自动更新

每天从 QQ 表情权威源（QFace）拉取新增表情 ID，只补内置表的缺口（内置表优先、只补缺），QQ 出新表情不用等插件发版。仅在「QQ 表情翻译」开启时生效。

24 小时制 HH:MM，例如 04:30（凌晨四点半）；格式非法按 04:30 处理。首次安装启动约 1 分钟后会先拉一次，不用等第一个凌晨。仅在「表情表自动更新」开启时生效。

回复指向（R1）

仅在「回复指向索引」开启时生效。

单个会话最多保留多少条「回给谁」记录，超出按先进先出淘汰。默认 50。
注入说明时最多回溯多少轮对话。越大说明越长、上下文占用越多。默认 3。

用户档案（R4）

仅在「用户档案注入」开启时生效。

超过这个字数的档案会被截断后再注入，防止个别超长档案挤占上下文。默认 600。

Token 用量展示（R9）

仅在「Token 用量展示」开启时生效。

每项填一个会话 UMO（aiocqhttp:GroupMessage:群号），多个用逗号、顿号或换行分隔；留空 = 任何会话都不显示。

调试日志

在 AstrBot 日志里打印每个功能的执行结果与跳过原因，排查「为什么没生效」时打开。

用户档案

按「平台 · 群」分组分类列出全部已记录的自助档案：档案按群隔离，同一个人在不同群可以是不同的档案（留空群号 = 私聊 / 未分群）。点「编辑」可直接改称呼、自述；群里用 /xbnext profile 维护的是同一份数据。

正在加载…
档案与「用户档案注入」开关解耦：这里存的档案只有在开关打开时才会喂给模型，关着也照样能查能改。

编辑档案

两个字段对应 /xbnext profile 的「称呼 / 自述」，留空的字段会被清掉。

档案按群隔离：填群号则只在该群生效；编辑时改群号等于把档案挪到新群。历史数据没填群号，显示在「私聊 / 未分群」分组里。
平台 + 群号 + 用户 ID 共同定位一份档案；新建时可手填，编辑已有档案时平台与用户 ID 不可改。
超长会在注入前被截断，默认上限 600 字（可在「行为微调」调整）。

指令

指令只做转发，逻辑在 xbnext/features/ 里。

/xbnext status查看各功能开关与 KV 可用性
/xbnext profile查看自己的档案
… 称呼 小明改称呼（别名：名字 / 昵称）
… 自述 <内容>改自述（别名：信息 / 描述）
… 清空删除自己的全部档案
档案与「用户档案」开关解耦：开关只决定喂不喂给模型，查看/设置/清空始终可用。字段只认「称呼 / 自述」两个，其余一律报错。 档案按群隔离：同一个人在不同群各存一份，私聊单独一份；回执抬头会标出当前范围（群 123456 / 私聊）。 控制台的「用户档案」页签按「平台 · 群」分组分类列出并编辑所有人的档案，与上面的指令写的是同一份数据。

新增一个功能

扩展点只有一处，详见 xbnext/features/base.py 顶部注释。

①建 features/my_thing/，写 Feature 子类
②填 key / name / description / order，实现 on_llm_request
③在 _conf_schema.json 加 enable_my_thing
④在 features/__init__.py 的 FEATURES 加一行
⑤在 tests/ 加测试
第 ③④ 步有机械校验兜底（test_structure.py），漏做直接红。要暴露子指令（像 /xbnext profile）就再填 command 并在 main.py 加一行静态转发。
