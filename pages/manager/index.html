💬 消息清洗与转义

引用占位清洗

请求前清理引用链里的 [Empty Text] / [Image unavailable] 占位噪声，把失效图片标注给模型，杜绝"凭空出现的空白图片"。修正类功能，开启会改写本轮请求。

QQ 表情翻译

把消息里的 face / mface 翻译成文字描述追加进请求。适配器默认不把表情放进正文，不开启等于表情全部丢失。修正类功能。

🎯 对话指向与档案

回复指向索引

记录 bot 每条回复"回给谁"，下一轮给出三方区分说明，避免把 A 问过的话套到 B 头上。新增行为，默认关闭。

用户档案注入

每轮按当前发言人注入其自助档案，让 bot 按档案理解用户而不是乱猜。档案按不可信输入清洗后注入，且不写入会话历史。新增行为，默认关闭。

⚡ 交互控制与用量

撤回取消请求

撤回刚发的消息时取消这条消息在飞的 LLM 请求 —— 省一次白烧的 token，也避免 bot 对着已撤回的消息回一整段；bot 已发出的回复也会连带撤回（aiocqhttp 下生效）。默认开启。

撤回先询问再取消

撤回时先问一句「要取消这次回复吗」，只有撤回者本人的回答算数（其他人回复无效）；回「是」取消并撤回回复，回「否」保留，10 秒内不回复自动取消。流程结束时询问消息会自动撤回。仅在上面的开关开启时生效。默认关闭。

历史图片瘦身

把对话历史里较旧消息携带的图片换成文字占位，大幅减少输入 token（一张截图动辄几千 token）。最近 6 条消息的原图保留，当轮刚发的图不受影响。改写类功能，默认关闭。

Token 用量展示

回复末尾追加一行本轮 token 用量（输入含缓存 / 输出 / 缓存），仅对「行为微调」里指定名单内的会话显示；端点不回报用量或缓存时不显示对应内容。默认关闭。

TTS 字数上限

当单次回复纯文本字数超过上限（默认 100 字，可在「行为微调」修改）时，自动跳过 AstrBot 语音合成（TTS）直接发送文字，避免长篇小说或大段分析卡死语音接口。默认开启。

🌐 平台与生效范围

私聊消息独立开关

开启后私聊消息也会触发本插件（如 TTS 与功能注入）；关闭后仅在允许的群聊中生效。默认关闭。

生效平台选择与管理

控制本插件在哪些平台运行。提供预设下拉选择、常用平台一键勾选，并支持添加自定义平台。

以逗号分隔平台标识（如 onebot, matrix）；留空或填 all 表示所有平台。上方勾选或添加会自动保存更新。

群聊总开关与分群独立功能控制

控制本插件在哪些群聊生效，并支持为每个群单独开关整个插件或单独开关某一项功能（未单独设置的项默认跟随全局开关）。

插件一键更新与检查

通过 AstrBot OpenAPI 接口一键检查并更新选定的插件。支持检测 GitHub 远程最新提交对比本地版本，一键自动拉取并热重载。此功能默认关闭。

在 AstrBot Web 控制台「开放接口」生成的 API Key，需具备插件管理权限。
AstrBot 服务的基础地址。若在同一服务器部署默认使用 http://127.0.0.1:6185，远程部署填写实际访问域名或 IP。
勾选需要一键检查与更新的插件（默认预设 xb 系列插件；未安装的插件会自动静默跳过）。

每天定时在设定的时间点（默认 04:30）自动检测并升级选定插件。如无更新则完全静默，有更新且升级完成自动向管理员推送通知报告。默认关闭。

每日执行自动检测与热重载更新的时间点（24 小时制 HH:MM，默认 04:30）。

新版本主动推送通知 (QQ 私聊)

当定时更新任务完成时，如果有插件更新成功，自动向设定的 QQ 号发送更新明细报告；无更新时完全静默不打扰。默认关闭。

填写接收更新提醒的管理员 QQ 账号（支持多个，使用英文或中文逗号隔开，例如 10000, 10001）。点击「发送测试通知」可向所有填写的 QQ 测试下发私聊消息。

自动读取已安装的所有第三方插件 metadata.yaml，监控 GitHub 远程最新版本并一并纳入更新提醒。默认关闭。

TTS 语音字数上限

仅在「TTS 字数上限」开启时生效。单次回复文本总字数超过此值时自动跳过语音合成直接发送文字（填 0 表示不限制）。

默认 100 字。例如写 3000 字短篇小说时会自动跳过 FishAudio TTS 直接发出文字。

引用占位处理方式

决定识别到引用占位符后怎么处理。仅在「引用占位清洗」开启时生效。

标注失效会把 [Image unavailable] 改写成中文说明（推荐）；直接删除会连同图片存在性一起抹掉；仅记录不改写请求。

移除失效图片路径

只删「能证实已失效」的本地路径，链接类（http/https/data）与无法离线判断的一律保留；正文里的裸 [Image] 一并标注失效，杜绝模型臆想出空白图。仅在「引用占位清洗」开启时生效。

表情翻译格式

{name} 会被替换成表情中文名，取不到名字时替换成表情 ID。仅在「QQ 表情翻译」开启时生效。

例如 [表情:得意]、[表情:ID12345]。

表情表自动更新

每天从 QQ 表情权威源（QFace）拉取新增表情 ID，只补内置表的缺口（内置表优先、只补缺），QQ 出新表情不用等插件发版。仅在「QQ 表情翻译」开启时生效。

24 小时制 HH:MM，例如 04:30；格式非法按 04:30 处理。首次安装启动约 1 分钟后会先拉一次，不用等第一个凌晨。

回复指向

仅在「回复指向索引」开启时生效。

单个会话最多保留多少条「回给谁」记录，超出按先进先出淘汰。默认 50。
注入说明时最多回溯多少轮对话。越大说明越长、上下文占用越多。默认 3。

用户档案

仅在「用户档案注入」开启时生效。

超过这个字数的档案会被截断后再注入，防止个别超长档案挤占上下文。默认 600。

Token 用量展示 · 群聊开关

仅在「Token 用量展示」开启时生效。直接在下方群聊开关列表中拨动开关即可加入/移出显示名单（自动保存）；也可在群内发 /xbnext token 一键切换。

指令

指令只做转发，逻辑在 xbnext/features/ 里。

/xbnext status查看各功能开关与 KV 可用性
/xbnext profile查看自己的档案（或加 @群友 查看他人）
… 小明 / 小明|学生极简一键设称呼或「称呼|自述」
… 称呼 小明改称呼（别名：名字 / 昵称 / 叫我小明）
… 自述 <内容>改自述（别名：信息 / 描述 / 我是…）
… 清空删除自己的全部档案
支持对话直接创建：开启「用户档案注入」后，用户在聊天中直接对机器人说「以后叫我阿光，我是做后端的」，AI 会自动调用工具保存档案。 档案按群隔离：同一个人在不同群各存一份，私聊单独一份；回执抬头会标出当前范围（群 123456 / 私聊）。 控制台的「用户档案」页签按「平台 · 群」分组分类列出并编辑所有人的档案，支持一键快选群聊与近期发言群友。

新增一个功能

扩展点只有一处，详见 xbnext/features/base.py 顶部注释。

①建 features/my_thing/，写 Feature 子类
②填 key / name / description / order，实现 on_llm_request
③在 _conf_schema.json 加 enable_my_thing
④在 features/__init__.py 的 FEATURES 加一行
⑤在 tests/ 加测试
第 ③④ 步有机械校验兜底（test_structure.py），漏做直接红。要暴露子指令（像 /xbnext profile）就再填 command 并在 main.py 加一行静态转发。
